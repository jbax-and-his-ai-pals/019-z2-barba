# Barba Edition status

The v1.05 tag marks the earlier MMC1 release. The development build uses
NES 2.0 Mapper 176 (FK23C), 512 KiB PRG, 512 KiB CHR, and 32 KiB banked WRAM.
It combines Barba Edition with the experimental *Where's Barba?* crossover
inside the same ROM. The portal is in Rauru. A wavy wipe leads to the crossover
title screen, and either Start + Select or the Moon ending returns Barba to
the same position and scroll in town. The older Mesen two-ROM prototype remains
available. [Crossover playtest instructions](TEST-PACK.md#experimental-waldo-portal)

The combined BPS includes *Where's Waldo?* game data as patch literals.
Public patch packaging is open. [Build inputs and outputs](BUILD.md)

For session-by-session history, see [docs/archive/CHANGELOG.md](archive/CHANGELOG.md). For the resolved November 15 audit, see [AUDIT-2026-11-15.md](AUDIT-2026-11-15.md).
